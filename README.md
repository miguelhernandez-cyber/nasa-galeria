# Galería del Cosmos

**Nombre del estudiante:** (miguel angel hernadez cardenas)

**API asignada:** NASA APOD (Astronomy Picture of the Day)

**Endpoint utilizado:** https://api.nasa.gov/planetary/apod?api_key=TU_CLAVE&count=12

**Descripción de la aplicación:** Galería de imágenes astronómicas de la NASA con buscador y detalles de cada imagen.

**Componentes desarrollados:** Header, SearchBar, Card, Footer

**Datos utilizados de la API:** title, url, date, explanation, media_type

**Funcionalidad de búsqueda o filtro:** Búsqueda por título y botón para limpiar el filtro.

**Funcionalidad adicional implementada:** Ver/ocultar detalles en cada tarjeta y contador de resultados.
